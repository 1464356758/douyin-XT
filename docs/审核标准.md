# 用户审核门槛（只有你能决定通过）

**图片审核**：原稿没有偏移；人物脸/服装/道具一致；镜头角度、焦段、景别、地平线、空间合理；手指数量与握持正确；物理光照和反射可信；风景自然摄影逻辑；没有提前出现本应保留悬念的元素。

**图片返修**：请说「第X张：把视角从俯视改为平视，人物和光线全部不变」等具体问题。优先局部重生成，不损坏已满意的画面。

**视频审核**：完整播放后检查动作与画面连贯、视线方向、自然表情、物体运动、台词在哪一秒出现、音画同步、音乐高潮、字幕无错字、结尾是否严格遵循原稿。不能看到实际视频的AI不能说“已经看过”。

**视频返修**：请说「6～8秒：快门声提前，保留其他镜头，只修第3镜头」。坚持局部修改原则。

**硬门禁**：任何GPT说“通过”“很好”都不代表用户通过。只有用户明确「图片满意」「视频定稿」，才可进入下一阶段。

**平台与隐私**：遵守AI生成内容标识、评论引用的合理授权和音乐素材授权；不要在公开GitHub提交未发布的真实人物肖像等私密素材。
