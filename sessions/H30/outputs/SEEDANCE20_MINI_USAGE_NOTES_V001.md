## 1. 型号与证据范围

核查对象是视频模型 Seedance 2.0 Mini。火山方舟公开模型列表对应 doubao-seedance-2-0-mini-260615，不与语言模型 Seed 2.0 Mini 混用。[S1]
官方 API 条目列出文生视频、首帧、首尾帧、全模态参考、视频编辑和延长；Mini 的 API 输出规格列为 480p/720p、24 fps、4～15秒、MP4。[S1]
这些是模型/API公开能力，不代表用户当前即梦网页、手机入口或会员账户开放了同样的按钮、规格和费用。即梦 Mini 的当前入口仍按实际界面操作。此前 CP0012 记录用户看到的是首帧/尾帧模式；本轮没有看到新界面，不能把该记录改成已验证可用全能参考。

## 2. 四种输入用途必须区分

|方式|素材的作用|执行规则|
|---|---|---|
|首帧|确定视频开始时的画面与动作状态|图放进实际首帧槽位，再描述之后的表演|
|首尾帧|提供动作开始和结束的两个画面|前态放首帧，后态放尾帧；还需描述中间过程|
|多图/全模态参考|提供人物、环境、风格等参考|逐项说明用途；不能把“两张参考图”等同于两个时序槽位|
|视频参考|提供动作、运镜等动态参考|说明借用的具体特征；参考生成、编辑原视频和延长原视频要明确区分|

依据：[S2][S3]。首尾帧是生成引导，不能保证中间动作、先后因果及人体细节自动通过；必须检查实际输出。
在首帧/首尾帧界面，不编造不存在的 @素材 控件。全能参考入口如确实开放，才按该入口支持的方式选择素材引用。

## 3. 提示词写法

- 优先明确：素材用途 → 开始状态 → 主体动作及触发顺序 → 结束状态 → 镜头 → 必要约束。这是针对 H30 的制作策略，不是官方强制语法。
- 官方创建视频任务文档建议中文提示词不超过500字、英文不超过1000词；这是建议，不写成 Mini 网页硬上限。[S2]
- 以自然、明确的动作描述为主，保留人物和场景必须一致的要点；避免大段重复的美学形容词盖过动作。
- 官方关键帧流程强调写清主体从首帧到尾帧的变化及运镜。[S5]
- 时间段可用于表达节奏；本轮未核实即梦 Mini 对时间戳具有逐帧强制执行能力。
- 官方系列指南支持音视频联合生成；官方 API 有 generate_audio 控制。网页是否有音频开关须看实际界面。[S3][S4] H30当前图1V002仍安排后期配准确原台词，不能宣称模型不能生成声音。
- 输出比例、时长、音频和分辨率如有实际控件，应以控件配置为准；提示词不能当作已完成的设置。

## 5. 生成与审核纪律

涉及扣积分的生成仍需用户先确认；当前30积分是旧会员界面记录，未核实今日实扣。API计费不替代即梦会员积分。
每次新提示词附一键复制文本和“生成后需要审核的内容”。
真实MP4审核至少覆盖：起始状态、动作先后、手指/器械、人物/服装/诊室、结尾状态、可剪长度和情绪。用户批准后才锁定镜头。
本轮只完成资料核验和记录；未点击生成，未消费积分，未上传私人媒体。
